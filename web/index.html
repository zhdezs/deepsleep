SuperAgent 架构 3.2.2 第一期

不只是「一个会调工具的聊天窗口」。deepsleep 正在升级成一套常驻、可调度、可自愈的多 Agent 系统： 把「理解与路由」和「执行」彻底分开，状态全部落库，长任务更稳、断点可续、Agent 之间互不污染上下文。

环境事件 Trigger→ 两级过滤 Fast / Slow→ Router · 共享上下文→ Worker Sessions · 上下文隔离→ Session 数据库持久化
已在 3.2.2 落地

Session 数据库

会话不再是一个截到 4000 字的快照文件，而是 data/sessions/<sid>.json + 索引， 带 kind(main/worker/router)、parentSid、state、时间戳与摘要；原子写入、旧数据自动迁移、可按状态查询。 这是 Router 与 Watchdog 的地基，也提供 sessionList / sessionGet 接口。

3.2.2 新增

Router 层：共享上下文 + 路由决策

每次「拆分任务」现在由 Router 统一收口：它持有一份共享简报（全局目标 / 权限边界 / 约束 / 同批角色 / 已产出路径）， 只把这个下发给你那几个上下文隔离的 Worker，彼此私有历史互不可见。路由判定是毫秒级规则， 为什么拆、拆几路，界面上写得明明白白（设置 → SuperAgent 架构 → 路由诊断）。

3.2.2 新增

Worker 会话落库 + 会话树

Router 与每个 Worker 都是 Session 库里真实存在的会话（kind=router/worker、parentSid、 状态从 active 走到 done/stopped、结果压成摘要），重启后还能按父子关系和状态查回来。 设置 → 查看会话架构 能直接看到这棵两层的树。

内核版：只装一个 Core，用网页操控这台电脑

适合「不想安装完整客户端」或「想在手机 / 另一台电脑上遥控本机」的人。

1
下载并解压内核版（解压即用，免安装）

Windows 用 deepsleep-core-3.2.2-win-x64.zip；Linux 用 deepsleep_3.2.2_amd64.deb / deepsleep-3.2.2-1.x86_64.rpm（或免安装的 deepsleep-3.2.2-linux-x64.tar.gz）；macOS 用 deepsleep-core-3.2.2-osx-arm64.tar.gz。桌面版和内核版能力完全一样，区别只是桌面版默认开窗口；没有桌面环境就加 --headless 只跑服务（Linux 桌面需要 libwebkit2gtk-4.1-0）。

⬇ deepsleep-core-3.2.2-win-x64.zip

2
运行内核：Windows 双击 deepsleep-core.exe，Linux / macOS 执行 ./deepsleep.sh

Windows 会打开本机首页；Linux / macOS 会直接开一个原生桌面窗口，双击即用（服务器 / SSH 加 --headless 只跑服务）。

同时会打印端口与配对令牌，方便在别的设备上连。

3
打开网页端连上来

本机首页点「内核版网页」即可；在外面就用 这个页面，填端口 + 令牌。
也可以直接把 #p=端口&t=令牌 拼在后面打开。

4
人在外面也想提问？加 --tunnel 走内网穿透

运行 deepsleep-core --tunnel，内核自动建一条免注册的公网隧道（手写隧道，直接用系统自带的 ssh，不用下任何组件）， 窗口里会打印一条配对链接（令牌已经带好）。

把那条链接在手机上打开、存成书签，出门在外也能直接指挥这台电脑。
打不开多半是运营商 DNS 不解析隧道域名，把手机 DNS 换成 114.114.114.114 再试。

桌面客户端不用敲命令：装好后在「设置 → 超远程提问」里点一下就能开 / 关隧道，能力和这里完全一样。
想用自己的穿透工具（frp / cpolar / ngrok / ssh -R 都行）：
deepsleep-core --public --tunnel-cmd "你的穿透命令"，内核会自己从输出里抓公网地址。

换令牌：deepsleep-core --new-token；换端口：--port 8888。
Linux / macOS 上数据默认放在 ~/.local/share/deepsleep（macOS 是 ~/Library/Application Support/deepsleep）。

安全边界（重要）

· 默认只监听 127.0.0.1；只有加 --public / --host 才监听网卡，只有加 --tunnel 才挂到公网。
· 所有接口都要配对令牌，跨域只放行官网与本机页面（隧道域名同源也放行）。
· 配对链接里就带着令牌 = 这台电脑的钥匙：不要截图发给别人、不要贴到公开场合。
· 令牌输错会越错越慢（递增延迟到 5 秒）再返回 401，防止被暴力猜。
· 用完直接关掉内核窗口，服务与隧道立刻停止。

超级连接：一串 6 位数字，把两台设备连起来

不用注册、不用配置、不用懂什么叫 NAT 打洞 —— 对着一串数字输进去就连上了，连上就能远程操作对方电脑。

1
在被操控的那台电脑上打开「超级连接」

桌面版：点工具栏的 🔗 图标 →「生成配对码」。
内核版 / CMD 模式：输入 打开超级连接（也可以 /superlink）。

2
把那串 6 位数字告诉另一台设备

配对码 5 分钟内有效，过期自动作废；连上以后也不会一直留着。

3
另一台设备打开超级连接页

手机 / 平板 / 另一台电脑的浏览器打开：
deepsleep.liziserver.site/superlink/?type=你的配对码
或者在自己的 deepsleep 里点 🔗 输入这 6 位数字。

打开超级连接页

4
连上就能用远程桌面

同一网络里走点对点局域网直连（延迟最低）；不在一个网络时，自动开一条临时加密隧道把两边牵上，连上之后立刻关掉隧道，数据保持点对点。

连上后点「打开远程桌面」：浏览器里直接看到对方屏幕，鼠标、键盘、滚轮、手机触屏都能操作；也能点「打开完整控制台」用整套能力。

它是怎么做到「傻子都会用」的

· 信令只传几 KB 的握手消息（默认 ntfy.sh），用来交换「我这个配对码的地址在哪」；
· 真正的画面与操作不经过第三方，在两台设备之间直连传输；
· 连接用的是一次性令牌，配对结束就撤销，不会泄漏本机常驻令牌；
· 生成配对码时会临时监听网卡（为了局域网直连），配对结束立刻换回只听 127.0.0.1；
· 想用自己的信令服务器：设环境变量 DEEPSLEEP_SIGNAL_BASE。

常见问题

要钱吗？
软件免费，默认接智谱的免费模型（GLM-4.7-Flash / GLM-4.6V-Flash / CogView-3-Flash），网页版还内置了一把免费 Key。想更快就把自己的 Key 填进设置。
我的聊天记录会被上传吗？
不会。会话、记忆、API Key 都存在你自己电脑上（网页版存在浏览器 localStorage）。只有发给模型的那段对话内容会走 API。
网页版和客户端差在哪？
网页版是纯前端，不能碰你的文件、跑命令、联网抓取；这些「动手」能力必须靠内核版或桌面客户端。
内核版会不会有风险？
它只监听 127.0.0.1 并要求配对令牌，外网直连不进；但令牌等于钥匙，别外传。用完关窗口即停。
为什么有时候会「限流 / 429」？
免费模型有并发限制，人多了就排队。填自己的 Key 或稍等重试即可。生成视频不在免费额度里，需要你自己的 Key（可在设置里复用图像用的那把）。
支持 macOS / Linux 吗？
支持。桌面版有 Linux（.deb / .rpm，x64 与 ARM64）和 macOS（内核版，Apple 芯片与 Intel），和 Windows 客户端是同一份内核，功能一个不少。Linux 上 sudo apt install ./deepsleep_*.deb 或 sudo dnf install ./deepsleep-*.rpm，macOS 解压 deepsleep-core-*-osx-*.tar.gz 后 ./deepsleep.sh。
也可以下免安装的 .tar.gz，解压后 ./deepsleep.sh 直接开原生桌面窗口；服务器 / SSH 加 --headless 就只跑内核服务、用浏览器连（Linux 桌面需要系统自带 libwebkit2gtk-4.1-0）。macOS 现在只发行内核版（.dmg 已下线，Apple 芯片上会被 Gatekeeper 判成「已损坏」）。
