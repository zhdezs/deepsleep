SuperAgent 架构

不是「一个会调工具的聊天窗口」，而是一套常驻、可调度、可自愈的多 Agent 系统。理解与执行分开，状态全部落库，长任务更稳，断点能续，Agent 之间不互相污染上下文。

环境事件 Trigger→ 两级过滤 Fast / Slow→ Router · 共享上下文→ Worker Sessions · 上下文隔离→ Session 数据库持久化

Session 数据库

会话不再是一个截到 4000 字的快照文件，而是 data/sessions/<sid>.json加一份索引，带 kind（main / worker / router）、parentSid、state、时间和摘要。原子写入，旧数据自动迁移，可以按状态查询。

Router 与 Worker

拆分任务由 Router 统一收口。它持有一份共享简报，里面有全局目标、权限边界、约束、同批角色和已产出的路径，只把这份简报下发给上下文隔离的 Worker。路由判定是毫秒级规则，为什么拆、拆几路可以在「设置 → SuperAgent 架构 → 路由诊断」里看。

会话树

Router 和每个 Worker 都是 Session 库里真实存在的会话，状态从 active 走到 done 或 stopped，结果压成摘要。重启后可以按父子关系和状态查回来，在「设置 → 查看会话架构」里能看到这棵两层树。

看门狗

定时巡检，把不在活跃列表里、超过设定时间没有更新的会话标记为停止，避免卡死的 Worker 一直占着资源。

分期路线

1Session 数据库状态落库、原子写、迁移、查询接口已完成
2Router + Worker 分层Router 持有共享上下文与路由决策，Worker 上下文隔离并落库已完成
3两级过滤 + TriggerFast Path 直通 Worker，Slow Path 走 Router；定时、文件事件已完成
4Watchdog独立监控卡死和超时的会话已完成
5多信道 + daemon复用超级连接隧道接 IM、邮件，工具执行抽到轻量 daemon规划中

这一层对普通用户无感，界面和用法不变，只是长任务更稳。

内核版：只装一个 Core，用网页操控这台电脑

适合不想安装完整客户端，或者想在手机、另一台电脑上遥控本机的情况。

1
下载并解压内核版，免安装

Windows 用 deepsleep-core-3.2.4-win-x64.zip；Linux 用 deepsleep_3.2.4_amd64.deb或 deepsleep-3.2.4-1.x86_64.rpm，也可以下免安装的 deepsleep-3.2.4-linux-x64.tar.gz；macOS 用 deepsleep-core-3.2.4-osx-arm64.tar.gz。桌面版和内核版能力一样，区别只是桌面版默认开窗口，没有桌面环境就加 --headless只跑服务。

deepsleep-core-3.2.4-win-x64.zip

2
运行内核。Windows 双击 deepsleep-core.exe，Linux 和 macOS 执行 ./deepsleep.sh

Windows 会打开本机首页，Linux 和 macOS 直接开一个原生窗口。服务器或 SSH 上加 --headless只跑服务。

启动时会打印端口和配对令牌，在别的设备上连接要用。

3
打开网页端连上来

本机首页点「内核版网页」。在外面就打开 这个页面，填端口和令牌，也可以直接把 #p=端口&t=令牌拼在地址后面。

4
人在外面想用，加 --tunnel走内网穿透

运行 deepsleep-core --tunnel，内核会用系统自带的 ssh 建一条免注册的公网隧道，不需要下任何组件，窗口里会打印一条带令牌的访问链接。

在手机上打开那条链接存成书签，出门也能用。打不开多半是运营商 DNS 不解析隧道域名，把手机 DNS 换成 114.114.114.114再试。

桌面客户端不用敲命令，装好后在「设置 → 超远程提问」里点一下就能开关隧道。想用自己的穿透工具也行，frp、cpolar、ngrok、ssh -R 都可以：deepsleep-core --public --tunnel-cmd "你的穿透命令"，内核会从输出里取公网地址。

换令牌用 --new-token，换端口用 --port 8888。Linux 和 macOS 上数据默认放在 ~/.local/share/deepsleep，macOS 是 ~/Library/Application Support/deepsleep。

安全边界

默认只监听 127.0.0.1，加 --public或 --host才监听网卡，加 --tunnel才挂到公网。
所有接口都要配对令牌，跨域只放行官网和本机页面。
访问链接里带着令牌，等于这台电脑的钥匙，不要截图外传，也不要贴到公开场合。
令牌输错会递增延迟，最多 5 秒再返回 401，防止暴力猜。
用完关掉内核窗口，服务和隧道立刻停止。

超级连接：一串 6 位数字连两台设备

不用注册，不用配置，也不用懂 NAT 打洞。输一串数字连上，就能远程操作对方电脑。

1
在被操控的电脑上打开「超级连接」

桌面版点工具栏的链接图标，选「生成配对码」。内核版或 CMD 模式输入 打开超级连接，也可以用 /superlink。

2
把 6 位数字告诉另一台设备

配对码 5 分钟内有效，过期作废，连上以后也不会留着。

3
另一台设备打开超级连接页

手机、平板或另一台电脑的浏览器打开 deepsleep.liziserver.site/superlink/?type=你的配对码，也可以在自己的 deepsleep 里输入这 6 位数字。

打开超级连接页

4
连上以后用远程桌面

同一网络走点对点直连，延迟最低。不在一个网络时自动开一条临时加密隧道，连上之后立刻关掉，数据仍然点对点。

点「打开远程桌面」就能在浏览器里看到对方屏幕，鼠标、键盘、滚轮、手机触屏都能操作。点「打开完整控制台」可以用整套能力。

怎么连的

信令只传几 KB 的握手消息，默认走 ntfy.sh，用来交换「这个配对码的地址在哪」。
画面和操作不经过第三方，在两台设备之间直连传输。
连接用的是一次性令牌，配对结束就撤销，不会泄漏本机常驻令牌。
生成配对码时会临时监听网卡，配对结束立刻换回只听 127.0.0.1。
想用自己的信令服务器，设环境变量 DEEPSLEEP_SIGNAL_BASE。

常见问题

要钱吗？
软件免费，默认接智谱的免费模型（GLM-4.7-Flash、GLM-4.6V-Flash、CogView-3-Flash），网页版还内置一把免费 Key。想更快就填自己的 Key。
我的聊天记录会被上传吗？
不会。会话、记忆、API Key 都存在你自己的电脑上，网页版存在浏览器 localStorage。只有发给模型的那段对话内容会走 API。
网页版和客户端差在哪？
网页版是纯前端，碰不到你的文件，也不能跑命令和联网抓取。这类操作要靠内核版或桌面客户端。
内核版会不会有风险？
它只监听 127.0.0.1，并要求配对令牌，外网直连进不来。令牌等于钥匙，别外传，用完关窗口就停。
为什么有时候会限流或返回 429？
免费模型有并发限制，人多就排队。填自己的 Key，或者过一会儿重试。生成视频不在免费额度里，需要自己的 Key，可以复用图像那把。
支持 macOS 和 Linux 吗？
支持。Linux 有 .deb 和 .rpm，x64 与 ARM64 都有；macOS 发的是内核版，Apple 芯片和 Intel 都有，和 Windows 客户端是同一份内核。Linux 上用 sudo apt install ./deepsleep_*.deb或 sudo dnf install ./deepsleep-*.rpm，macOS 解压 deepsleep-core-*-osx-*.tar.gz后执行 ./deepsleep.sh。也可以下免安装的 .tar.gz，服务器和 SSH 环境加 --headless只跑内核服务。
