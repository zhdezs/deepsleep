内核版：只装一个 Core，用网页操控这台电脑

适合「不想安装完整客户端」或「想在手机 / 另一台电脑上遥控本机」的人。

1
下载并解压内核版（解压即用，免安装）

⬇ deepsleep-core-2.2.0-win-x64.zip

2
双击 deepsleep-core.exe

窗口里会打印端口与配对令牌，并自动打开本机首页。

3
打开网页端连上来

本机首页点「内核版网页」即可；在外面就用 这个页面，填端口 + 令牌。
也可以直接把 #p=端口&t=令牌 拼在后面打开。

换令牌：deepsleep-core.exe --new-token；换端口：--port 8888。

安全边界（重要）

· 内核版只监听 127.0.0.1，外网机器直连不进来；能连上的只有你自己浏览器里打开的页面。
· 所有接口都要配对令牌，跨域只放行官网与本机页面。
· 令牌 = 这台电脑的钥匙：不要截图发给别人、不要贴到公开场合。
· 用完直接关掉内核窗口，服务立刻停止。

常见问题

要钱吗？
软件免费，默认接智谱的免费模型（GLM-4.7-Flash / GLM-4.6V-Flash / CogView-3-Flash），网页版还内置了一把免费 Key。想更快就把自己的 Key 填进设置。
我的聊天记录会被上传吗？
不会。会话、记忆、API Key 都存在你自己电脑上（网页版存在浏览器 localStorage）。只有发给模型的那段对话内容会走 API。
网页版和客户端差在哪？
网页版是纯前端，不能碰你的文件、跑命令、联网抓取；这些「动手」能力必须靠内核版或桌面客户端。
内核版会不会有风险？
它只监听 127.0.0.1 并要求配对令牌，外网直连不进；但令牌等于钥匙，别外传。用完关窗口即停。
为什么有时候会「限流 / 429」？
免费模型有并发限制，人多了就排队。填自己的 Key 或稍等重试即可。
支持 macOS / Linux 吗？
目前只发行 Windows x64；界面是 HTML，理论上换外壳就能移植。
