0 · 五分钟上手

最快路径：Windows 用户下安装版 → 双击装好 → 直接开聊（不用先配 Key）。

1
下载：到下载页，海外选 GitHub 的 deepsleep-Setup.exe； 国内选 Gitee，下两个 .part 分片 + deepsleep-merge-setup.exe 合并器。
2
安装：双击 Setup（Gitee 用户先双击合并器，它会自动拼好并启动安装）。 安装程序会顺手把 .dslt / .dslp 关联到 deepsleep，以后双击扩展包就自动装。
3
开聊：首次启动内置一把免费 Key，直接输入「帮我看看这个文件夹里有什么」就能用。 想用更快的模型，去 ⚙ 设置 → 模型 填自己的 API Key。
4
让它动手：默认是 work 模式，跑命令前会先弹确认； 想全自动就把模式换成 boom。纯聊天用 chat。
✅ 不用注册、不用登录、不用配环境。会话、记忆、Key 全存在你自己电脑上。
⚠️ 第一次运行 Windows 可能提示「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」即可（未做代码签名）。

2 · 安装方式（全）

Windows · 桌面客户端

方式文件怎么做
安装版（推荐）deepsleep-Setup.exe双击 → 自动装到本机、建开始菜单、写文件关联、支持 OTA 静默升级
便携版deepsleep-3.2.1-win-x64.zip解压到任意文件夹 → 双击 deepsleep.exe。不写注册表，可放 U 盘
网页版无需文件直接打开 网页版
内核版deepsleep-core-3.2.1-win-x64.zip解压 → deepsleep-core.exe → 浏览器打开提示的地址

要求 Windows 10 1809 以上 / Windows 11，x64。自包含发布，不需要先装 .NET；WebView2 运行时缺失时安装程序会引导补装。

Gitee 分片下载 + 合并器（国内用户看这里）

Gitee 单附件上限 100 MB，安装包被切成两片，三样都要下。

deepsleep-Setup.exe.part1＋ deepsleep-Setup.exe.part2＋ deepsleep-merge-setup.exe→ deepsleep-Setup.exe
1
在下载页把「下载源」切到 Gitee，下载 part1、part2 和合并器，放进同一个文件夹。
2
双击 deepsleep-merge-setup.exe。它会自动找齐分片、按序拼接、校验 SHA-256，拼好后直接启动安装程序。
3
看到 a60f607e… 之类的校验值和「启动安装程序」就说明成功了。合并出来的 deepsleep-Setup.exe 和 GitHub 整包字节一致。
⚠️ 分片缺一片、编号不连续、或者被浏览器改了名字（(1) 后缀），合并器会明确报错并拒绝生成一个坏 exe——按提示改回名字再试。

Linux / macOS

系统文件 / 命令
Ubuntu / Debian x64sudo apt install ./deepsleep_3.2.1_amd64.deb（ARM64 用 _arm64.deb）
Fedora / RHEL / openSUSEsudo dnf install ./deepsleep-3.2.1-1.x86_64.rpm（ARM64 用 aarch64.rpm）
任意 Linux（免安装）解压 deepsleep-3.2.1-linux-x64.tar.gz → ./deepsleep.sh 直接开原生窗口；服务器加 --headless 只跑服务
macOS（Apple / Intel）解压 deepsleep-core-3.2.1-osx-arm64.tar.gz（或 -osx-x64）→ ./deepsleep.sh

Linux 桌面原生窗口需要 libwebkit2gtk-4.1-0。macOS 目前只发行内核版——.dmg 已下线（Apple 芯片上会被 Gatekeeper 判成「已损坏」）。

内核版：只装一个 Core，用浏览器控电脑

1
下载并解压 deepsleep-core-3.2.1-win-x64.zip（Linux / macOS 对应 .tar.gz）。
2
Windows 双击 deepsleep-core.exe；Linux / macOS 执行 ./deepsleep.sh。默认进入命令行对话。
3
用浏览器打开 core/ 网页端，填本机地址与配对令牌即可远程操控；同一局域网手机也能连。
4
想在外网用，加 --tunnel 开会生成免注册的公网地址 + 带令牌的配对链接，存成手机书签即可。
内核只监听 127.0.0.1 并要求令牌，外网直连进不来。配对链接就是钥匙，别截图外传。用完关窗口即停。

网页版（零安装）

直接打开 app/，内置免费 Key，开箱即聊，聊天记录只存浏览器 localStorage。 它是纯前端，不能读写文件、跑命令、联网抓取——这些能力需要内核版或桌面客户端。

升级 / 卸载

  • 升级：客户端自己检查新版本（国内走 Gitee、国外走 GitHub），点一下自动下载安装并重启。也可以在设置里手动「检查更新」。
  • 卸载：Windows 设置 → 应用 → deepsleep → 卸载；便携版直接删文件夹。卸载会保留 data\ 里的会话与记忆，想彻底清掉再手动删。
  • 降级 / 多版本共存：用便携版解压到不同目录即可，互不干扰。

3 · 配置模型

开箱自带免费 Key；想更快、更稳或换模型，去 ⚙ 设置 → 「模型」页。

① 什么都不配（默认）

内置免费 Key 自动接入：GLM-4.7-Flash 聊天、GLM-4.6V-Flash 看图、CogView-3-Flash 画图。打开就能用，缺点是有并发限流。

② 填自己的 API Key

设置 → 模型：选平台（智谱 / 硅基流动 / OpenAI / 自定义），填 API 地址、Key、模型名、协议格式。支持一键联网拉模型列表、先「测试连接」再保存。

③ 一键绑定

点「一键绑定」走 OAuth 授权页，拿到的 Key 直接落盘，不用手抄。按供应商保存配置档案，之后可以一键切回某一家。

④ 本地模型（Ollama）

打开「本地模型」开关，填 Ollama 地址与模型名；设置里还能一键引导安装 Ollama。完全离线，不上传任何对话。

图像 / 视觉 / 视频是独立配置

⚙ 设置里有「图像」「视频」页：生成图片、看懂图片、生成短视频各自的接口地址、Key、模型名都能单独换，可复用同一把 Key，也能分别指向不同网关。

  • 看图：主模型是多模态时图片直接作为输入（模型会自动跳过「看图」工具）；不是多模态才走独立的视觉模型。
  • 生成视频：不在免费额度内，需要自己的 Key。支持同步返回 / 提交后轮询 / 自定义查询地址模板。
⚠️ 免费模型会限流（429）。人多了排队，填自己的 Key 或稍等重试即可。

5 · 工作模式与极速模式

模式行为适合
chat纯聊天，不调用干活工具问答、写作、翻译
work（默认）能调全部工具，跑命令 / 写文件前先弹确认日常，最稳
boom全自动，任何命令和文件操作都不问 trusted 环境、批量任务

⚡ 极速模式

只压缩人设、砍掉冗余推理步骤，依然能调用全部普通工具（运行命令、Python、文件、搜索、深度研究、看图、画图、操作电脑、自定义工具…）。 但为了真的「极速」，它不接知识库：不注入目录索引、不列查询工具、误调直接拒绝。

极速模式有

完整工具参数说明、自定义工具清单、长期记忆、扩展创作规范、工具调用能力

极速模式没有

知识库检索、最终回复阶段的 JSON 约束与工具清单（省 token、更快出字）

需要查软件自身的格式规范、参数细节时用普通模式 + 「查知识库」；要快就开极速。

7 · 扩展包 .dslt / .dslp

两种包本质都是 zip：工具包加能力，皮肤包改外观。装过 deepsleep 的电脑，双击即装。

🧩 .dslt 自定义工具

根目录 manifest.json + 入口脚本。指定 python / cmd / powershell / node 运行时，输入通过第 1 个参数或 DEEPSLEEP_TOOL_INPUT 传入，stdout 直接当结果。例：科学计算器、单位换算、批量改名。

🎨 .dslp 皮肤包

根目录 theme.json + 可选 CSS。改配色变量、圆角、背景，还能写 @keyframes 做自定义动效。皮肤是叠加层，不会替换亮/暗模式自带的 CSS。

三种获得方式

1
双击安装（最省事）：安装程序已把两种扩展名关联到 deepsleep。双击 .dslt / .dslp 就自动装；应用正在运行时不会弹第二个窗口，切回窗口会自动重新扫盘。也可右键「打开方式 → deepsleep」。
2
让 AI 现场做：直接说「给我做一个科学计算器工具」或「把界面换成深海蓝紫风格」。软件会预先灌注完整的扩展格式规范，模型能自己写文件 → 打包 → 安装，一条龙。
3
手搓：建个文件夹写好清单和脚本，用「制作扩展」工具打包，或手动压成 zip 后改扩展名。完整字段说明见 docs/extensions.md。

管理

⚙ 设置 → 🧩 扩展：工具可以逐个启用 / 停用 / 删除，皮肤可以「使用」或「关闭叠加皮肤」。 也可以直接把 .dslt / .dslp 路径粘到「安装扩展包」输入框里点安装。

装好的工具立刻进入模型的工具清单（右下角数量会变）。如果没刷新，切一下窗口焦点即可触发自动重扫。

8 · 主题与皮肤（3.2.1 新）

亮色和暗色各有一整套不同的 CSS，不是同一套换几个颜色变量。

模式内置 CSS长什么样
深色theme-dark.css · dsh 深眠漂移氛围光、星点闪烁、流光用户气泡、工具光条、输入框聚焦光环
浅色theme-light.css · dsh 晨光雾白画布、墨绿强调色、柔和玻璃高光、克制的淡入动效

点右上角 ☀️ / 🌙 整套启停、即时生效，不用重载；两套都尊重系统的「减少动态效果」设置，上次选择会被记住。

皮肤是叠加层

  • 装了 .dslp 皮肤后，它盖在当前模式之上；切主题不会把它换掉，皮肤也不会反过来改主题。
  • 觉得配色不搭，点「关闭叠加皮肤，恢复当前模式默认」就回到上面两套之一。
  • 内置的两套 CSS 不是扩展包，不需要也不能「安装 / 删除」。
想改自带样式？直接编辑 ui/theme-dark.css / ui/theme-light.css；两套都是全局选择器，只启用其中一份，改起来互不干扰。

9 · 知识库（3.2.1 新）

随程序分发 7 章内置文档：总览 · 工具参数手册 · 扩展格式规范 · 文本与输出规范 · 界面与设置 · 发布与排错 · Session 与架构。 目的是让模型在回答「deepsleep 自己怎么用 / .dslt 该怎么写」时有据可查，而不是凭空编字段。

  • 普通模式会拿到目录索引，需要时用「查知识库」按主题检索相关章节（不灌全文，避免撑爆上下文）。
  • 可以把自己写的 .md 放进 data/knowledge/，支持 front matter 的标题 / 摘要 / 关键词，会自动纳入检索。
  • 极速模式完全不接知识库：不注入索引、不列工具名、误调直接拒绝——查一轮就不极速了。

10 · 记忆 / 技能 / 拆分任务

🧠 长期记忆

告诉它「我习惯用 VS Code」「项目在 D:\work」，它会调用「记住」存下来，之后每轮自动带上。说「忘掉第 3 条」就调「删除记忆」。左栏「🧠 记忆」可查看管理。

🧩 技能 / 模板

把常做的事存成技能与快捷指令，一句话触发整套流程。只有你明确点名技能时才会注入说明，不做关键词硬塞。

⚡ 拆分任务

大任务由主助手自己拆成多个子 Agent 并行执行（命令 / Python / 文件 / 搜索 / 研究 / 画图），最后汇总结果，不用手动切标签页。

11 · 超级连接与超远程提问

🔗 超级连接（远程桌面）

点顶栏 🔗 拿一串 6 位配对码，两台设备一连：同网段走点对点直连，不同网络自动开临时加密隧道。 连上后能在浏览器里看对方画面、动鼠标键盘，手机触屏也行。

📡 超远程提问（内网穿透）

桌面客户端在「设置 → 超远程提问」点一下开隧道；内核版加 --tunnel 一条命令搞定。 生成的是免注册公网地址 + 带令牌的配对链接，手机存成书签，人在外面也能指挥家里这台电脑。

⚠️ 配对链接里就带着令牌，等于这台电脑的钥匙：不要截图发给别人、不要贴到公开场合。用完关掉隧道。

12 · SuperAgent 架构 3.2.1 卖点

deepsleep 正在从「一个会调工具的聊天窗口」升级为一套常驻、可调度、可自愈的多 Agent 系统。

环境事件 Trigger→ 两级过滤 Fast / Slow→ Router（共享上下文）→ Worker Sessions（上下文隔离）→ Session 数据库持久化

旁路还有：订阅直通、多信道交互（IM / GitHub / 邮件）、轻量 daemon 执行环境、Watchdog 外部自愈。 核心思路是——把「上下文」和「执行」彻底分开：Router 只管理解与路由，Worker 各干各的互不污染，状态全部落库，卡死了有外部看门狗拉起来。

为什么值得现在就用

已经在 3.2.1 落地

会话不再是一个截到 4000 字的快照文件，而是带 kind / parentSid / state / 时间戳 / 摘要的独立记录；原子写入、旧数据自动迁移、可按状态查询。这是 Router 和 Watchdog 的地基。

已经在 3.2.1 落地

「拆分任务」已经让主助手自己拆出多个子 Agent 并行干活、最后汇总；会话按 sid 隔离。等于 Worker 的执行雏形先跑起来了。

13 · 数据位置与隐私

内容位置
会话 / 配置 / 记忆<安装目录>\data\（便携版在解压目录）
会话记录（3.2.1）data\sessions\<sid>.json + index.json
已装扩展data\tools\ / data\skins\ / extensions.json
自建知识文档data\knowledge\
生成图片 / 研究报告 / 截图data\images\ / data\research\ / data\shots\
排错日志data\ui.log、ext.log、app-install.log、crash.log

网页版浏览器 localStorage，不落服务器

聊天记录不会上传；只有发给模型的那段对话会走 API。软件不收集任何遥测数据。客户端只检查版本时访问 GitHub / Gitee。

14 · 命令行参数（内核版 / 高级）

参数作用
--headless只跑内核服务，不开窗口（服务器 / SSH 场景）
--tunnel开内网穿透，生成带令牌的公网配对链接
--install-ext "<路径>"安装 .dslt / .dslp 后退出（双击扩展包走的就是这条）
--port <端口>指定内核服务监听端口
# Linux / macOS 服务器：只跑服务，手机用浏览器连
./deepsleep.sh --headless --tunnel

# 命令行直接装一个扩展包
deepsleep-core.exe --install-ext "D:\work\科学计算器.dslt"

15 · 故障排查

现象怎么办
按钮点了没反应 / 界面没变化先按 Ctrl+R 重载界面（WebView2 偶尔吃缓存）；再看 data\ui.log。发版后如果设置页内容错位，多半是跑着旧 DLL，重新装一次即可。
双击 .dslt 没装进去右键 →「打开方式」→ 选 deepsleep 并设为默认；或在设置 → 扩展里粘路径手动装。日志看 data\app-install.log。
Gitee 合并器报「分片缺失 / 编号不连续」确认 part1、part2、合并器在同一个文件夹，且文件名没有 (1) 之类的下载后缀。
429 / 限流免费模型并发限制，稍等重试或填自己的 Key。
生成视频失败视频不在免费额度里，需要自己的 Key；检查「设置 → 视频」里的接口地址、模型名、轮询方式。
模型不调用工具 / 只会聊天确认模式不是 chat；极速模式也能调工具。模型本身太弱时换成支持 function calling 的。
「操作电脑」截图是空的需要真实交互桌面会话；远程 / 服务会话里没有可截图的桌面（屏幕宽度为 0）。
皮肤点了没生效3.2.1 起皮肤是叠加层，不会再重载整页。看 data\ext.log 确认命令到了内核；内置的两套主题 CSS 不需要「使用」。
Linux 打不开窗口装 libwebkit2gtk-4.1-0；纯服务器加 --headless 用浏览器连。
macOS 提示「已损坏」只从 .dmg 安装会遇到（已下线）。改用 deepsleep-core-*-osx-*.tar.gz 内核版。

还没解决？

带上下面的信息去 GitHub Issues 提一下： 版本号、操作系统、复现步骤，以及 data\ui.log / ext.log / crash.log 的最后几十行。 Gitee 用户也可以在 Gitee Issues 反馈。
