0 · 五分钟上手

Windows 用户下安装版，装好就能聊，不用先配 Key。

1
下载。到下载页，海外选 GitHub 的 deepsleep-Setup.exe，国内选 Gitee，下两个 .part分片和 deepsleep-merge-setup.exe合并器。
2
安装。双击 Setup，Gitee 用户先双击合并器，它会拼好包再启动安装。安装程序会把 .dslt和 .dslp关联到 deepsleep，以后双击扩展包就能装。
3
开聊。首次启动自带一把免费 Key，直接输入「帮我看看这个文件夹里有什么」就能用。想换更快的模型，去设置里的模型页填自己的 Key。
4
让它动手。默认是 work模式，跑命令前会弹确认。想全自动就换 boom，只想聊天用 chat。
不用注册，不用登录，也不用配环境。会话、记忆、Key 都存在你自己的电脑上。
第一次运行 Windows 可能提示「Windows 已保护你的电脑」，点「更多信息」再点「仍要运行」。安装包没有做代码签名。

1 · 选哪种形态

同一份内核，四种外壳，按场景挑一个。

形态适合谁能操作文件 / 命令安装
桌面客户端
推荐		日常主力，Windows 或 Linux 桌面能安装版或便携版
网页版只想聊天、看图、画图，或公共电脑不能，纯前端零安装，浏览器打开
内核版 + 网页不想装完整客户端，或手机遥控本机，或服务器能解压即用
万能安装程序给不熟悉命令行的朋友装 Linux 或 macOS能一个小脚本自动判断平台
桌面客户端自带内核服务。在设置里点一下「超远程提问」，手机在外网也能连回来操控这台电脑，和内核版是同一份实现，功能不缺。

2 · 安装方式

Windows 桌面客户端

方式文件怎么做
安装版（推荐）deepsleep-Setup.exe双击，自动装到本机，建开始菜单，写文件关联，支持静默升级
便携版deepsleep-3.2.4-win-x64.zip解压到任意文件夹，双击 deepsleep.exe。不写注册表，可以放 U 盘
网页版无需文件打开 网页版
内核版deepsleep-core-3.2.4-win-x64.zip解压，运行 deepsleep-core.exe，浏览器打开提示的地址

要求 Windows 10 1809 以上或 Windows 11，x64。自包含发布，不用先装 .NET。缺 WebView2 运行时的话，安装程序会引导补装。

Gitee 分片下载与合并

Gitee 单附件上限 100 MB，安装包切成两片，三样都要下。

deepsleep-Setup.exe.part1+ deepsleep-Setup.exe.part2+ deepsleep-merge-setup.exe→ deepsleep-Setup.exe
1
在下载页把下载源切到 Gitee，下 part1、part2 和合并器，放进同一个文件夹。
2
双击 deepsleep-merge-setup.exe，它会找齐分片，按序拼接，校验 SHA-256，拼好以后直接启动安装程序。
3
看到校验值和「启动安装程序」就说明成功了。拼出来的 deepsleep-Setup.exe和 GitHub 上的整包字节一致。
分片缺一片、编号不连续，或者被浏览器改了名字（多了 (1)后缀），合并器会报错并拒绝生成坏文件。按提示改回文件名再试。

Linux 与 macOS

系统文件 / 命令
Ubuntu / Debian x64sudo apt install ./deepsleep_3.2.4_amd64.deb，ARM64 用 _arm64.deb
Fedora / RHEL / openSUSEsudo dnf install ./deepsleep-3.2.4-1.x86_64.rpm，ARM64 用 aarch64.rpm
任意 Linux（免安装）解压 deepsleep-3.2.4-linux-x64.tar.gz，执行 ./deepsleep.sh开原生窗口。服务器加 --headless只跑服务
macOS（Apple / Intel）解压 deepsleep-core-3.2.4-osx-arm64.tar.gz或 -osx-x64，执行 ./deepsleep.sh
不确定选哪个下 deepsleep-universal-3.2.4.zip，里面的脚本会自动识别系统并下载对应包

Linux 的原生窗口需要 libwebkit2gtk-4.1-0。macOS 目前只发内核版，.dmg 已经下线，因为 Apple 芯片上会被 Gatekeeper 判成「已损坏」。

内核版：只装一个 Core，用浏览器控电脑

1
下载并解压 deepsleep-core-3.2.4-win-x64.zip，Linux 和 macOS 用对应的 .tar.gz。
2
Windows 双击 deepsleep-core.exe，Linux 和 macOS 执行 ./deepsleep.sh，默认进入命令行对话。
3
用浏览器打开 core/网页端，填本机地址和配对令牌就能远程操控，同一局域网里的手机也能连。
4
想在外网用就加 --tunnel，会生成一个免注册的公网地址和带令牌的访问链接，存成手机书签即可。
内核只监听 127.0.0.1并要求令牌，外网直连进不来。访问链接就是钥匙，别截图外传，用完关窗口即停。

网页版（零安装）

打开 app/就能用，内置免费 Key，聊天记录只存在浏览器的 localStorage。它是纯前端，不能读写文件、跑命令、联网抓取，这些能力要靠内核版或桌面客户端。

升级与卸载

  • 升级：客户端自己检查新版本，国内走 Gitee，国外走 GitHub，点一下自动下载安装并重启。也可以在设置里手动检查。
  • 卸载：在 Windows 设置的「应用」里找到 deepsleep 卸载，便携版直接删文件夹。卸载会保留 data\里的会话和记忆，想彻底清掉再手动删。
  • 多版本共存：用便携版解压到不同目录即可，互不影响。

3 · 配置模型

自带免费 Key。想更快、更稳或换模型，去设置里的模型页。

什么都不配

内置免费 Key 自动接入，GLM-4.7-Flash 聊天，GLM-4.6V-Flash 看图，CogView-3-Flash 画图。打开就能用，缺点是有并发限流。

填自己的 API Key

在模型页选平台（智谱、硅基流动、OpenAI、自定义），填 API 地址、Key、模型名和协议格式。支持联网拉模型列表，也能先测试连接再保存。

一键绑定

点「一键绑定」走 OAuth 授权页，拿到的 Key 直接存下，不用手抄。配置可以按供应商存档，之后一键切回某一家。

本地模型

打开「本地模型」开关，填 Ollama 地址和模型名，设置里还能引导安装 Ollama。完全离线，对话不出本机。

图像、视觉、视频的配置是独立的

设置里有「图像」和「视频」两页，生成图片、看懂图片、生成视频各自的接口地址、Key、模型名都能单独换。可以复用同一把 Key，也可以分别指向不同的网关。

  • 看图：主模型本身是多模态时，图片直接作为输入，模型会自动跳过「看图」工具；不是多模态才走独立的视觉模型。
  • 生成视频：不在免费额度里，需要自己的 Key。支持同步返回、提交后轮询、自定义查询地址模板。

模型列表会缓存

拉到的列表按「API 地址 + 协议」存在 data/models-cache.json，下次启动不用再等网络，打开模型面板就能看到。缓存超过 6 小时会在面板打开时静默刷新，新结果和缓存逐条比对，真的变了才覆盖并提示。最多保留最近 8 个来源。

上下文上限可以自己定

用量环按「中文 1 字约 1 token，其余 4 字符约 1 token」估算，窗口大小先从模型名里的 32k、128k、1m推断，认不出按 128k 算，本地模型按 32k。模型名是中转别名看不出窗口时，点圆环打开面板，在「上下文上限」里选 32k、64k、128k、200k、1M，或者直接填数字，选「跟随模型」恢复自动推断。改完立即生效并写进配置。

免费模型会限流，返回 429 就是排队了。填自己的 Key 或者过一会儿重试。

5 · 工作模式与极速模式

模式行为适合
chat只聊天，不给文件和命令类工具，其余工具都能用问答、写作、翻译
work（默认）能调全部工具，跑命令和写文件前先确认，确认后 1 小时内同类操作不再问日常使用
boom全自动，命令和文件操作都不问信任的环境、批量任务

极速模式

压缩人设，砍掉多余的推理步骤，普通工具照样能调。为了真的快，它不接知识库：不注入目录索引，不列查询工具，误调直接拒绝。

极速模式保留

完整的工具参数说明、自定义工具清单、长期记忆、扩展创作规范、工具调用能力

极速模式去掉

知识库检索、最终回复阶段的 JSON 约束和工具清单，省 token，出字更快

要查软件自身的格式规范、参数细节，用普通模式加「查知识库」。只求快就开极速。

6 · 内置工具清单

模型自己判断该用哪个，不用手动点。右下角的工具数可以随时查看全集。

类别工具
动手运行命令、运行 Python 脚本、读取文件、写入文件、打开文件、操作电脑（鼠标键盘，每步截图交给模型判断）
信息网络搜索、深度研究（多轮搜索、抓正文、出报告）、抓取网页、看图、渲染图片
创作生成图片、生成视频
连接器GitHub（查仓库、搜代码、建 issue），点「用 GitHub 登录」在浏览器授权一次即可，不用手建令牌；Blender（写 bpy 脚本建模，按扩展名导出 .blend、.glb、.gltf、.obj、.stl、.fbx），点「连接」自动找本机 Blender。两个都要在设置里的连接器页连上，没连时模型看不到对应的工具
记忆与扩展记住、删除记忆、查知识库、安装扩展、制作扩展
编排拆分任务，主助手把大任务拆成多个子 Agent 并行执行，最后汇总
Blender 连接器：点「连接」会去 Program Files\Blender Foundation、LocalAppData\Programs和 PATH 里找 blender.exe，再跑一次 blender --version验证，路径配错在这一步就会报出来。找不到可以点「填路径」手动指定。执行用 blender --background --factory-startup --python，不弹界面。
GitHub 连接器：点「用 GitHub 登录」，浏览器会打开授权页，输入界面上那 8 位代码，点 Authorize。令牌由 GitHub 直接发回本机，不用复制粘贴。想要更小的权限可以点「用令牌」自己建一个 PAT；想用自己注册的 OAuth App，在设置里填它的 Client ID，记得勾上 Enable Device Flow。
连接器凭据：只存在本机的 data\connectors.json，用 DPAPI 和 AES-256-GCM 加密，不进配置文件，也不上传。断开连接会把凭据从本机删掉。
操作电脑：能点按钮、填表单、操作别的软件。每一步先确认（work 模式），执行后截图交给视觉模型判断窗口标题、可点元素和相对坐标，再决定下一步。失败或超时会如实说明，不会假装完成。
工具是本机能力，不是沙箱。boom模式下模型可以无确认地跑任何命令，只在自己的机器上开。

7 · 扩展包 .dslt 与 .dslp

两种包都是 zip。工具包加能力，皮肤包改外观，装过 deepsleep 的电脑双击就能装。

.dslt自定义工具

根目录放 manifest.json和入口脚本。运行时可以指定 python、cmd、powershell、node，输入通过第一个参数或环境变量 DEEPSLEEP_TOOL_INPUT传入，stdout 直接当结果。比如科学计算器、单位换算、批量改名。

.dslp皮肤包

根目录放 theme.json，可选 CSS。能改配色变量、圆角、背景，也能写 @keyframes做动效。皮肤是叠加层，不会替换深色或浅色主题自带的 CSS。

三种做法

1
双击安装。安装程序已经把两种扩展名关联到 deepsleep，双击 .dslt或 .dslp就会装。应用正在运行时不弹第二个窗口，切回窗口会自动重新扫盘。也可以右键「打开方式」选 deepsleep。
2
让 AI 现场做。直接说「给我做一个科学计算器工具」或者「把界面换成深海蓝紫风格」。软件会预先给模型完整的扩展格式规范，它能自己写文件、打包、安装。
3
自己写。建个文件夹写好清单和脚本，用「制作扩展」工具打包，或者压成 zip 改扩展名。字段说明见 docs/extensions.md。

管理

在设置的扩展页可以逐个启用、停用、删除工具，皮肤可以「使用」或者「关闭叠加皮肤」。也可以把 .dslt或 .dslp的路径粘到「安装扩展包」输入框里点安装。

装好的工具立刻进入模型的工具清单，右下角的数量会变。没刷新就切换一下窗口焦点，会触发重扫。

8 · 主题与皮肤

深色和浅色各有一整套 CSS，不是同一套换几个变量。

模式内置 CSS长什么样
深色theme-dark.css · dsh 深眠漂移氛围光、星点、流光用户气泡、工具光条、输入框聚焦光环
浅色theme-light.css · dsh 晨光雾白画布、墨绿强调色、柔和的玻璃高光、克制的淡入动效

点右上角切换，整套启停，立即生效，不用重载。两套都跟随系统的「减少动态效果」设置，上次的选择会被记住。

皮肤是叠加层

  • 装了 .dslp皮肤后，它盖在当前模式之上。切换主题不会把它换掉，皮肤也不会反过来改主题。
  • 配色不搭的话，点「关闭叠加皮肤，恢复当前模式默认」就回到上面两套之一。
  • 内置的两套 CSS 不是扩展包，不需要也不能安装或删除。
想改自带样式，直接编辑 ui/theme-dark.css或 ui/theme-light.css。两套都是全局选择器，同时只启用一份，互不干扰。

9 · 知识库

随程序分发 7 章内置文档：总览、工具参数手册、扩展格式规范、文本与输出规范、界面与设置、发布与排错、Session 与架构。模型回答「deepsleep 自己怎么用」「.dslt 该怎么写」时有据可查，不会凭空编字段。

  • 普通模式会拿到目录索引，需要时用「查知识库」按主题检索相关章节，不灌全文，避免撑爆上下文。
  • 自己写的 .md可以放进 data/knowledge/，支持 front matter 里的标题、摘要、关键词，会自动纳入检索。
  • 极速模式完全不接知识库，不注入索引，不列工具名，误调直接拒绝。

10 · 记忆、技能与拆分任务

长期记忆

告诉它「我习惯用 VS Code」「项目在 D:\work」，它会调「记住」存下来，之后每轮对话自动带上。说「忘掉第 3 条」就调「删除记忆」。左栏的记忆按钮可以查看和管理。

技能与模板

把常做的事存成技能和快捷指令，一句话触发整套流程。只有你明确点名技能时才会注入说明，不做关键词硬塞。

拆分任务

大任务由主助手拆成多个子 Agent 并行执行，命令、Python、文件、搜索、研究、画图这些都能分出去，最后汇总结果，不用手动切标签页。

11 · 超级连接与超远程提问

超级连接（远程桌面）

点顶栏的链接按钮拿一串 6 位配对码，两台设备就能连上。同网段走点对点直连，不同网络自动开临时加密隧道。连上后能在浏览器里看到对方画面，用鼠标键盘操作，手机触屏也行。

超远程提问（内网穿透）

桌面客户端在「设置 → 超远程提问」点一下开隧道，内核版加 --tunnel一条命令搞定。生成的是免注册的公网地址和带令牌的访问链接，手机存成书签，人在外面也能用家里这台电脑。

访问链接里带着令牌，等于这台电脑的钥匙。不要截图发给别人，也不要贴到公开场合。用完关掉隧道。

12 · SuperAgent 架构

deepsleep 从一个会调工具的聊天窗口，变成一套常驻、可调度、可自愈的多 Agent 系统。

环境事件 Trigger→ 两级过滤 Fast / Slow→ Router（共享上下文）→ Worker Sessions（上下文隔离）→ Session 数据库持久化

核心思路是把上下文和执行分开。Router 只管理解与路由，Worker 各干各的，互不污染，状态全部落库，卡住了有看门狗拉起来。旁路还有订阅直通、多信道交互（IM、GitHub、邮件）和轻量 daemon 执行环境。

已经能用的部分

Session 数据库

会话不再是截到 4000 字的快照文件，而是带 kind、parentSid、state、时间戳和摘要的独立记录。原子写入，旧数据自动迁移，可以按状态查询。

Router 层

每次拆分任务由一个 Router 会话收口。它持有共享简报，里面有目标、权限、约束、同批角色和已产出的路径，再下发给 Worker。路由判定是毫秒级规则，能解释清楚。

Worker 会话隔离

每个 Worker 是 Session 库里独立会话，parentSid指向 Router。执行中是 active，完成是 done，中断是 stopped，产出压成摘要。重启后能按父子关系和状态查回来。

发送即路由

每条消息先到常驻 Router。命中多步骤、多领域或者明确要求并行，就走慢路径：Router 用它自己的模型规划分工，优先从你的 Worker 名单里挑人，再并行执行和汇总。否则走快路径，主助手直接答。chat 模式的拆分门槛更高，宁可不拆。开关在「设置 → SuperAgent 架构 → 自动路由」。

触发器

每隔 N 分钟、每天某个时间、或者某个文件一变动，就把一句话当成用户消息交给 Router，和你手打走同一条链路。在「设置 → 扩展 → 触发器」里增删。

看门狗

启动时把上次遗留的「运行中」Worker 收成 stopped。运行中每 30 秒巡检一次，只收状态写着 active、本进程没在跑、并且超时没动静的会话。真在跑的长任务不会被误杀，常驻的 Router 也不受影响。

可观测

设置里的「查看会话架构」直接列出 Router 到 Worker 的两层树和统计。「路由诊断」贴一段任务就能看到判定路径、拆几路、为什么。输入框右侧的圆环点开是上下文用量面板，能看占比、条数、上限来源，也能改上限。

13 · 数据位置与隐私

内容位置
会话、配置、记忆<安装目录>\data\，便携版在解压目录
会话记录data\sessions\<sid>.json加 index.json
已装扩展data\tools\、data\skins\、extensions.json
自建知识文档data\knowledge\
生成的图片、报告、截图data\images\、data\research\、data\render\、data\shots\
排错日志data\ui.log、ext.log、app-install.log、crash.log
初始提示词data\AGENT.md，所有对话共享，只能在设置里改
网页版浏览器 localStorage，不落服务器

聊天记录不会上传，只有发给模型的那段对话会走 API。软件不收集遥测数据，检查版本时才会访问 GitHub 或 Gitee。

14 · 命令行参数

参数作用
--headless只跑内核服务，不开窗口，适合服务器和 SSH
--tunnel开内网穿透，生成带令牌的公网访问链接
--install-ext "<路径>"安装 .dslt 或 .dslp 后退出，双击扩展包走的就是这条
--port <端口>指定内核服务监听端口
# Linux / macOS 服务器：只跑服务，手机用浏览器连
./deepsleep.sh --headless --tunnel

# 命令行直接装一个扩展包
deepsleep-core.exe --install-ext "D:\work\科学计算器.dslt"

15 · 故障排查

现象怎么办
按钮点了没反应，界面没变化先按 Ctrl + R重载界面，WebView2 偶尔会吃缓存，然后看 data\ui.log。发版后设置页内容错位，多半是还在跑旧 DLL，重装一次即可。
双击 .dslt没装进去右键「打开方式」选 deepsleep 并设为默认，或者在设置的扩展页粘路径手动装。日志看 data\app-install.log。
合并器报分片缺失或编号不连续确认 part1、part2 和合并器在同一个文件夹，文件名没有 (1)之类的下载后缀。
返回 429免费模型有并发限制，稍等重试，或者填自己的 Key。
生成视频失败视频不在免费额度里，需要自己的 Key。检查「设置 → 视频」里的接口地址、模型名和轮询方式。
模型不调用工具，只会聊天确认模式不是 chat。极速模式也能调工具。模型本身太弱的话，换成支持 function calling 的。
「操作电脑」截图是空的需要真实的交互桌面会话。远程或服务会话里没有可截图的桌面，屏幕宽度为 0。
皮肤点了没生效皮肤是叠加层，不会重载整页。先看 data\ext.log确认命令到了内核。内置的两套主题 CSS 不需要「使用」。
Linux 打不开窗口装 libwebkit2gtk-4.1-0。纯服务器加 --headless，用浏览器连。
macOS 提示已损坏这是用 .dmg 安装才会遇到的，.dmg 已经下线。改用 deepsleep-core-*-osx-*.tar.gz内核版。

还没解决

带上版本号、操作系统、复现步骤，以及 data\ui.log、ext.log、crash.log的最后几十行，去 GitHub Issues提一下。Gitee 用户也可以在 Gitee Issues反馈。
