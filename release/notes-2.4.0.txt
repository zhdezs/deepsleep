2.4.0：超远程提问（内网穿透）——装上这一版，内核就能挂到公网，人在外面也能指挥这台电脑。① 一条命令开隧道：deepsleep-core --tunnel 会自动建一条免注册的公网隧道（内置 cloudflared，第一次自动下载），启动后窗口里直接打印一条配对链接（令牌已经带好），手机浏览器打开、存成书签即可；已经有自己的穿透工具（frp / cpolar / ngrok / ssh -R）就用 --public --tunnel-cmd "你的穿透命令"，内核会从命令输出里自己抓公网地址、同样打印配对链接。② 安全边界没放宽：默认仍然只监听 127.0.0.1，只有 --public / --host 才监听网卡，只有 --tunnel 才挂公网；所有接口都要配对令牌，跨域只放行官网、本机页面和隧道域名同源，别家网站照样 403；令牌输错会递增延迟（400ms×次数，封顶 5 秒）再返回 401，不封 IP（隧道下来的来源都是 127.0.0.1，封了会误伤）。③ 不带令牌的 /api/ping 只回名字和版本，端口、运行时长、数据目录都要带令牌才给，免得公网上被人扫出来。④ 隧道地址会写进数据目录的 tunnel.txt，窗口里也给了「打不开先换 DNS 到 114.114.114.114」的提示（实测部分运营商 DNS 不解析 trycloudflare）。其余与 2.3.2 一致：命令输出中文不乱码、运行的命令点开看完整输出、桌宠资源回收、兜底面板不再误报、chat 模式不落盘、代码块兜底不吞正文、DSML 工具标记直接执行、截断自动续写、Agent 名片 + 按需派工、集群名册只增不减、内核跨平台（Windows / Linux / macOS）。⑤ 桌面客户端也补齐了内核版的全部能力：以前只有内核版（deepsleep-core）能对外提供网页端与内网穿透，现在把服务端（HTTP + 隧道 + 令牌校验 + 跨域策略）抽成两边共用的同一份实现，桌面版装上就默认监听本机、在「设置 → 超远程提问」里点一下就能开 / 关公网隧道，手机在外网一样能连上来操控这台电脑；窗口类命令由桌面外壳接管（真的去显示 / 隐藏 / 退出窗口）。两边不会再出现能力差。
