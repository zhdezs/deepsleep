deepsleep AI 助手 · 安装说明
========================================

一、安装
  双击「安装 deepsleep.cmd」，会弹出图形安装界面：
    1. 选择安装位置（默认 %LOCALAPPDATA%\Programs\deepsleep，不需要管理员权限）
    2. 勾选是否创建桌面快捷方式、安装完是否立即启动
    3. 点「开始安装」，进度条走完即安装完成
  安装完成后会自动创建开始菜单快捷方式，并在「设置 → 应用 → 已安装的应用」
  里登记卸载入口。

  静默安装（给脚本/批量部署用）：
    powershell -ExecutionPolicy Bypass -File install.ps1 -Silent -InstallDir "D:\Apps\deepsleep" -NoDesktopShortcut -NoLaunch

二、首次使用要配置模型
  程序本身不含 API Key，每台电脑必须单独配置：
    打开 ⚙ 设置 → 填写 API 协议格式、API 地址、模型名、API Key → 保存
  也支持三种协议：OpenAI 兼容（DeepSeek / 智谱 / 硅基流动 / Groq / OpenRouter）、
  Anthropic Claude、Google Gemini。
  不想用在线 API 的话，可以在设置里点「一键安装 Ollama + 大模型」，切到本地模型跑，
  不消耗额度。

三、数据位置
  所有用户数据都在安装目录的 data 文件夹内：
    config.json       模型与 API 配置（含 Key）
    conversations.json 对话历史
    memory.json       长期记忆
    runtime_state.json 断点恢复状态（程序被杀/关机后仍可恢复未完成任务）
    skills\           技能目录
  升级安装不会覆盖这些文件；换电脑时把整个 data 目录拷过去即可。

四、卸载
  方式一：设置 → 应用 → 已安装的应用 → deepsleep AI 助手 → 卸载
  方式二：双击安装目录里的「卸载 deepsleep.cmd」
  卸载界面可选择是否保留用户数据（默认保留）。
  静默卸载：
    powershell -ExecutionPolicy Bypass -File uninstall.ps1 -Silent                 # 保留用户数据
    powershell -ExecutionPolicy Bypass -File uninstall.ps1 -Silent -RemoveUserData # 连数据一起删

五、系统要求
  Windows 10 1809 及以上（推荐 Windows 11，毛玻璃效果更好），x64。
  程序自带 .NET 运行时，无需另装任何依赖。
  Windows 11 上可享受亚克力毛玻璃界面，Windows 10 会自动退回普通背景。

六、在线更新（OTA）
  程序左下角有「⬆ 检查更新」按钮，启动时也会自动检查（可在设置里关闭）。
  升级流程全自动：读取更新源 → 下载新安装包（带 SHA256 校验）→ 退出程序 →
  静默覆盖安装到原目录 → 自动重启，用户数据（API Key、对话、记忆、模型）不受影响。

  更新源（⚙ 设置 → 更新源）支持三种填法：
    1. GitHub 仓库（推荐）：填 owner/repo，例如 lichenghan/deepsleep
       客户端走 GitHub Releases API，自动取最新 tag 里的 deepsleep-Setup.exe
    2. 清单直链：https://你的地址/deepsleep/update.json
    3. 本地 / 局域网共享：D:\release\update.json 或 \\服务器\共享\update.json
  仓库里没有 Release 资产时，客户端会自动退回读取仓库根目录的 update.json（main / master 都试）。

  国内网络下载慢 / 中途断掉？不用管：
    · 客户端会先用直连，失败或中断时自动切换国内加速镜像（ghproxy.net / gh-proxy.com /
      hub.gitmirror.com）继续下，已下好的部分不用重来（断点续传）
    · 下完仍然按 GitHub 官方给的 SHA256 校验，镜像只负责搬字节，改不了内容

  发布方（你）发新版本的 GitHub 流程：
    1. 改 csproj 里的 <Version>，重新编译 deepsleep-Setup.exe
    2. GitHub 仓库 → Releases → 新建 Release，tag 写 v1.0.1，说明写本次更新内容
    3. 把 deepsleep-Setup.exe 作为资产上传
    4. 客户端左下角就会出现「有新版」，点一下就自动升级
  想用 update.json 兜底：运行 make-update.ps1 -Version 1.0.1 -Notes "本次更新内容"，
  把生成的 update.json 提交到仓库根目录即可。

八、私有仓库 / GitHub 令牌（可选，绝对安全）
  需要用「检查更新」拉私有仓库，或者想提高 GitHub API 限额时：
    1. 双击程序目录下 tools\set-github-token.ps1（也可以在 ⚙ 设置里点「🔑 录入 GitHub 令牌」）
    2. 弹窗里粘贴令牌 → 保存（脚本会顺手校验，并显示账号名与 API 限额）
  安全说明：
    · 令牌用 Windows DPAPI（当前用户）加密后存到 data\github.token
    · 不写进 config.json，不写日志、不回显，窗口标题与命令行里也没有
    · 文件权限收紧到只有当前 Windows 账号可读写；换电脑或换账号都解不开
    · 删除令牌：tools\set-github-token.ps1 -Remove ；只校验：-VerifyOnly
  令牌权限建议（都选只读）：公开仓库提高限额 → public_repo；私有仓库 OTA → repo（只读）或 Contents: Read

九、脚本目录
  所有辅助脚本都在程序目录的 tools 子目录里，不会和主程序混在一起：
    tools\set-github-token.ps1      录入 GitHub 令牌（DPAPI 加密）
    tools\publish-github-release.ps1 把新版本一键发布到 GitHub Releases（OTA 用）
