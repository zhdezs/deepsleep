deepsleep v3.2.2 —— SuperAgent 架构第 2 期 + 全新输入框

● SuperAgent 第 2 期：Router + Worker 分层（架构图里第 2 块）
  · 每次「拆分任务」现在由 Router 会话统一收口：它持有共享简报——全局目标、权限边界、
    约束、同批角色、已产出路径，以及同一会话上一次 Router 留下的结论（组织记忆）。
  · 每个 Worker 是独立会话（kind=worker、parentSid 指向 Router），上下文互相隔离、
    私有历史互不可见；状态 active → done/stopped，产出压成摘要落库，重启后还能查回来。
  · 路由判定是毫秒级确定性规则，不额外花一次模型调用：多步骤编号、并列词、跨领域角色、
    任务体量、显式要求并行都会加分；chat（只读）模式门槛更高，不会把闲聊拆成一堆子智能体。
  · 新增「设置 → SuperAgent 架构」：
      - 查看会话架构：Router → Worker 两层树 + 统计（活跃/已停/主会话数）
      - 路由诊断：贴一段任务，直接看到判定路径、拆几路、为什么
  · 拆分任务卡片上每路都标了自己的 Worker 会话号，点开就是完整产出。

● 输入框重做（按新设计）
  · 一个圆角卡片装下全部控件：上面打字，底部一条工具行。
  · 从左到右：＋ 菜单（上传 / 极速 / 本地 / 联网 / 重新生成 / 清空）、权限模式药丸、
    技能与指令；右侧：上下文用量圆环、模型选择、圆形发送按钮。
  · 上下文用量圆环：蓝色进度 + 悬停显示 token 数与消息条数；≥60% 橙色、≥85% 红色。
    按中英文字符估算，只为提示"该开新对话了"，不做精确计费。
  · 发送按钮状态可视化：↑ 发送、红色 ■ 停止、绿色 ▶ 继续。
  · 亮/暗两套主题都已适配。

● 其他
  · 新增命令：sessionTree / routeDecide / ctxUsage（文档与知识库已同步）。
  · Router / Worker 的 sid 段与集群会话错开，启动时按索引恢复计数器，重启不覆盖旧记录。
