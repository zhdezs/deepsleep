3.2.3 · 输入框三个面板 + 模型列表持久化

## 输入框：点得开了
上一版把输入框改成一张卡片，但用量环只有 22px、模型只是个名字，看不到细节。这版把它们做成可展开面板（点外面自动收起）：

- **上下文用量面板**（点右下圆环）：大号占比 + 进度条 + 消息条数 / 当前模型 / 上限来源，并且能直接改**上下文上限**——跟随模型、32k / 64k / 128k / 200k / 1M 一键切，或自填 token 数。名字里没有窗口信息的模型（中转别名、自定义名）终于不会一直按 128k 估算了。
- **模型面板**（点模型名）：完整列表 + 搜索，当前项高亮，顺手显示窗口大小；换模型后用量环立刻按新窗口重算。
- **技能面板**（点 🤖）：把已安装的技能逐条列出来（名字、文件数），点一行展开说明和磁盘路径；下面接着快捷指令，点一下直接填进输入框。

## 模型列表不再每次重新拉
- 拉到的列表按「API 地址 + 协议」缓存到 `data/models-cache.json`，**启动就能显示**，不用等网络、也不会每次开面板都空着转圈。
- 每次打开面板时若缓存超过 6 小时就静默联网刷新；新结果和缓存比对（模型 id + 免费标记，顺序无关），**真的变了才覆盖**，并提示「模型列表已更新：N 个」。
- 缓存只留最近 8 个来源，换平台来回切也不会把文件撑大。

## 修掉的问题
- 模型列表/预设药丸的选中项原来用 `--chipon`（主题里是实色深青）配蓝字，几乎看不清；改成半透明蓝底。
- 深色主题下上下文进度条的底槽过亮，改成中性半透明。

## SuperAgent（延续 3.2.2）
第 1 期（Session 数据库）与第 2 期（Router + Worker）已随 3.2.2 发布；这版没有改动架构层，只补了界面与缓存。设置 → SuperAgent 架构里仍可查看会话树与路由诊断。
