3.1.0：外部 API 从「手动填地址 + 背模型名」改成「选平台 → 绑 Key → 联网拉模型」三步走；
       OpenRouter / NanoGPT 做到点一次同意就完成绑定（真 OAuth PKCE），其余 16 家走引导式，
       内置 18 家带免费额度的平台可选。

① 内置 18 家「有免费额度」的平台，设置面板里选一家就自动填好 API 地址和协议格式，
   不用再去查文档抄 URL：
   硅基流动（注册送 14 元 ≈ 2000 万 token）、魔搭 ModelScope（每天 2000 次）、
   OpenRouter（25+ 款 :free 永久 0 元）、NVIDIA NIM（82+ 免费模型、无每日 token 上限）、
   Groq、Cerebras、智谱 BigModel（Flash 系永久免费）、Moonshot Kimi、Gemini / Google AI Studio、
   阿里云百炼、火山方舟（豆包）、百度千帆、Mistral、PPIO 派欧云、无问芯穹、GitHub Models、
   腾讯混元、阶跃星辰，最后一项是「自定义」兜底。
   每个平台下面直接写明免费额度的真实口径（是「每天 N 次」还是「送多少钱」），并标注要不要梯子。

② 支持**一键绑定**的平台做成了真·一键：OpenRouter 和 NanoGPT 开放了第三方应用 OAuth，
   点一下就在应用内打开授权页，登录并同意后 Key 自动填好、自动落盘、自动拉回模型列表 ——
   全程不用手动创建、复制、粘贴。
   实现走的是标准 OAuth 2.0 PKCE（和 Codex / Claude Code / Cline 同一套做法），并且：
   · 授权页开在**应用自己的窗口**里，不是跳去系统浏览器 —— 整个流程一个窗口走完，不用 Alt+Tab 切回来；
   · 平台跳回本机回调地址时，在网络层直接拦下这次导航取走授权码 —— 不占端口、不弹防火墙，
     也绕开了「浏览器把 127.0.0.1 当其它网站拦掉」这个坑；
   · 应用内窗口不支持时（非 Windows 外壳）自动退回「系统浏览器 + 只监听回环的临时服务」，
     功能不丢，只是体验退一步；
   · PKCE 用 S256，state 做防重放校验，授权码换 Key 全程不过第三方。

   其余 16 家（硅基流动、魔搭、智谱、Groq、NVIDIA NIM…）不开放第三方 OAuth，只能在控制台
   手工建 Key，所以保留「按引导绑定」：一键跳到申请页 → 复制 → 粘回来 → 点「测试连接」验证。
   界面上按平台能力自动切换，能一键的显示「⚡ 一键绑定」，不能的显示「按引导绑定」，
   不会让用户点了按钮撞到一个必然报错的授权页。
   （魔搭虽然支持 OAuth 登录，但换回的是身份令牌，调不了推理接口，因此同样归在引导式。）

③ 「绑定账号」在各家的技术约束下没法对**所有**平台做成 GitHub 那种 OAuth 一键授权，理由见上。
   两家能一键的已经做到极致，其余家做成半自动三步：
   · 点「🔑 按引导绑定」直接跳到该平台的申请页（不同平台的申请页路径差很多，
     以前要自己在官网里翻半天，现在一步直达）；
   · 粘回来点「🔌 测试连接」，真的发一个最小请求，30 秒内回一句「连接正常 · 模型名 · 耗时」，
     或者把原始报错（401 无效 Key / 404 地址或模型名不对 / 429 限流）直接显示出来；
   · Key 或模型写错时当场就知道，不用先保存再去对话里试错。

③ 新增「🔄 联网获取模型列表」：不用再背模型 ID 了。点一下就去该平台拉当前可用的模型清单，
   在下面下拉里挑一个，自动填进「API 模型名」。
   · 能拿到定价的平台（如 OpenRouter）会把确认免费的模型标上 🆓 并排在最前面；
   · 模型 ID 是会变的（DeepSeek 的 Flash 已改名 deepseek-flash，智谱的旗舰是 glm-5.3 而不是 glm-5），
     联网拿的是平台当下的真实清单，比内置预设更不会过期；
   · 地址推导覆盖四种协议：OpenAI 兼容的 /models、Gemini 原生 ?key=、Anthropic 的 x-api-key，
     以及各家 /v1 /v3 /v4 前缀不同的情况。

④ 免费模型预设从 5 条扩到 28 条，按平台分组，并把「免费」和「用赠送额度跑的付费模型」分开标注。
   实测校验过的模型 ID：硅基流动上智谱的命名空间是 zai-org/（不是 zhipuai / THUDM），
   DeepSeek 官方 Flash 是 deepseek-flash。预设是离线兜底 —— 懒得联网时直接选一个就能用。

⑤ 修了一个真正会导致「选对了也发不出去」的 bug：回怼引擎（以理服人）的 ApplyConfig 一直漏设
   Format / Thinking / ReasoningEffort 三项，只设了地址、模型名和 Key —— 于是无论界面里选的是
   什么协议，它永远按 OpenAI 格式发请求。选了 Gemini / Claude 协议的用户，这个引擎必然报错。

⑥ 修了另一个必错项：设置面板里选「模型预设」以前只回填地址和模型名，不回填协议格式。
   从 Gemini 预设切到硅基流动预设时，格式还停在 gemini，请求直接失败，用户完全看不出为什么。
   现在地址、模型名、协议格式三件套一起换。

⑦ 换平台时会把模型名清空，并提示先去拉列表 —— 各家的模型 ID 不通用，把上一家的模型 ID
   带过去只会得到 404。保存时如果填了 Key 却没有模型名，会当场拦下来不让存（只用本地 Ollama
   的用户不受影响，Key 为空就不校验）。

⑧ 版本号收敛到单一来源。以前安装器里写死过 3.0.4，载荷已经升到 3.0.5 了注册表里还是 3.0.4；
   内核也漏同步过一次（升到 2.1.0 还显示 2.0.0）。现在外壳、内核、安装器三处都读
   src\Directory.Build.props 里的同一个 <Version>，安装器通过 MSBuild 的 XmlPeek 取，
   运行期用 AssemblyMetadata 读，改一处全生效。

⑨ 其余与 3.0.5 一致：超级连接（远程桌面 + 对话）、超远程提问、CMD 模式、Agent 集群名片、长期记忆、
   技能、网络搜索 + 深度研究、AGENT.md 初始提示词、命令与文件合并成可展开卡片、思考折叠、
   截断自动续写、跨平台桌面版三件套（Linux deb/rpm、macOS dmg、免安装 tar.gz）。
