3.0.1：手写内网穿透 + 修「超级连接页打开后显示没令牌」 + 跨平台桌面版。① 远程桌面 / 超级连接的隧道不再依赖 cloudflared：直接驱动系统自带的 ssh 反向隧道（serveo.net / localhost.run 自动择优），零下载、免安装组件，连上先自检、断了自动重建；同时最多建两条候选、实测速度后只留最快的那条，公网地址不再随机变慢。② 修掉「从超级连接页打开后提示缺少配对令牌」：免费隧道会在页面外插一层浏览器警告页，它的 Continue 表单（GET action=""）会把 ?t=令牌 整个顶掉；现在令牌改放在 # 片段里（片段不发给服务器、也不受表单影响），网页端另外做了 localStorage 兜底，点一次之后换页也不会再问。③ 远程桌面帧瘦身：PNG 逐行自适应滤波 + 5 位色量化，同样画质下一帧体积降到约 1/2.8，慢链路明显更顺；画面没变化时不发帧（最多 10 秒补一帧保活）。④ 跨平台桌面版：Linux（x64 / ARM64）与 macOS（Apple 芯片 / Intel）的解压即开原生桌面窗口（Linux 需 libwebkit2gtk-4.1-0），同一个包加 --headless 就是内核模式；macOS 只发行桌面版，不再单独发内核版。⑤ 桌面版必须有的 Core 功能一个不少：内核与界面共用同一份服务端实现，窗口类指令由外壳接管。其余与 3.0.0 一致：超级连接（6 位配对码 · 点对点直连 · 内置远程桌面）、超远程提问（--tunnel + 手机配对链接 + 令牌防暴破）、CMD 模式、Agent 集群与名片、长期记忆、技能、网络搜索 + 深度研究、AGENT.md 初始提示词、命令与文件合并成可展开卡片、思考内容折叠、截断自动续写、Gitee 线路加速。⑥ Linux / macOS 的桌面版换成「照 Windows 桌面版改」的外壳（Photino 装系统自带 WebView：Linux = WebKitGTK、macOS = WKWebView），界面与内核和 Windows 客户端完全同一份，功能一个不少（桌宠、超级连接、超远程提问、Agent 集群名片、命令与文件合并卡片都在），不再是内核版套个窗口；安装包补齐成三件套：Linux 出 .deb（Debian / Ubuntu，x64 与 ARM64）和 .rpm（Fedora / RHEL / openSUSE，x86_64 与 aarch64），macOS 出 .dmg（GitHub Actions 在 macos-14 上拼 deepsleep.app 再 hdiutil 打包、ad-hoc 签名），免安装的 .tar.gz 照旧发行；Linux 桌面需要系统自带 libwebkit2gtk-4.1-0 与 libgtk-3-0（.deb 已写进依赖）。
